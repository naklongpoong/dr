Core-Satellite คือวิธีจัดพอร์ตที่แบ่งเป็นแกนหลักที่มั่นคงกับ Satellite ที่ลองความคิดเฉพาะตัว จะได้เลือกหุ้นเองได้โดยไม่ต้องเอาทั้งพอร์ตไปเสี่ยง บทนี้อธิบายหลักคิดและตัวอย่างเลขคณิต

1. แนวคิด

  • Core: สัดส่วนใหญ่ของพอร์ต ใช้ ETF ดัชนีกว้างที่ต้นทุนต่ำ กระจายไปหลายร้อยบริษัท (บท 82) เป้าหมายคือให้ได้ผลตอบแทนใกล้ตลาดโดยไม่ต้องคัดเอง
  • Satellite: สัดส่วนเล็กกว่า ใช้ลงทุนในหุ้นรายตัว ETF กลุ่มหรือธีม (บท 83) หรือสินทรัพย์อื่นตามมุมมอง

สัดส่วนที่ใช้ไม่มีค่ามาตรฐาน เป็นการตัดสินใจของแต่ละคนตามความรู้และความสามารถรับความเสี่ยง (บท 86)

2. ตัวอย่างสมมติ: Satellite ช่วยจำกัดความเสียหาย

พอร์ต 1,000,000 บาท แบ่ง Core 80% (800,000) และ Satellite 20% (200,000)

สถานการณ์SatelliteCoreผลต่อพอร์ตรวม
Satellite ขาดทุน 50%−100,000เท่าเดิม−10%
Satellite เพิ่ม 100%+200,000เท่าเดิม+20%
Core ลด 30% และ Satellite ลด 50%−100,000−240,000−34%

แสดงว่า Satellite ที่ผิดพลาดแค่ไหนก็กระทบพอร์ตจำกัด และ Satellite ที่ถูกก็ไม่ได้ยกพอร์ตขึ้นไปมาก ความเสี่ยงของพอร์ตส่วนใหญ่ยังมาจาก Core (ตัวอย่างสมมติ ไม่ใช่การคาดการณ์)

3. ข้อดีและข้อจำกัด

  • ข้อดี: แยกความตั้งใจออกจากความรู้สึก ส่วนที่ตั้งใจเสี่ยงมีขอบเขตชัด วัดผลของ Satellite แยกได้ ว่าเลือกหุ้นเองได้ดีกว่าถือ Core เฉยๆ หรือไม่
  • ข้อจำกัด: Core ที่เป็น ETF ดัชนีถ่วงตามมูลค่าอาจกระจุกตัวอยู่กับกลุ่มใหญ่อยู่แล้ว และ Satellite ในกลุ่มเดียวกันจะซ้ำ (ดูตัวอย่าง 41.7% ใน บท 83)
  • ต้องมีวินัยไม่ปล่อยให้ Satellite ที่ขึ้นแรงโตจนกลายเป็นส่วนใหญ่ของพอร์ต (บท 90)

4. ตั้งกฎ Satellite ก่อนซื้อ

  • กำหนดเพดานรวมของ Satellite และเพดานต่อหนึ่งตำแหน่ง (บท 89)
  • เขียนเหตุผลที่ซื้อ ตัวเลขที่จะตรวจ และเงื่อนไขขาย (บท 97, บท 98)
  • ประเมินผลเทียบกับ Core ที่ช่วงเวลาเดียวกัน ถ้า Satellite ไม่ชนะ Core ต่อเนื่องหลายปีหลังหักต้นทุนและภาษี ก็ถามตัวเองว่าควรย้ายเงินไป Core หรือไม่
  • ต้นทุนและภาษีของการซื้อขายบ่อยใน Satellite ดูใน บท 21, บท 29

5. ตัวอย่างคำนวณ: Satellite ชนะ Core หรือเปล่า

พอร์ต 1,000,000 บาท Core 800,000 บาท ผลตอบแทนปีนี้ +8% Satellite 200,000 บาท แบ่งเป็นหุ้นรายตัว 4 ตัว ตัวละ 50,000 บาท ได้ผลตอบแทน −40%, +10%, +60% และ −20%

  • กำไรขาดทุนของ Satellite = −20,000 + 5,000 + 30,000 − 10,000 = +5,000 บาท หรือ 5,000 ÷ 200,000 = +2.5%
  • กำไรของ Core = 800,000 × 8% = 64,000 บาท
  • พอร์ตรวมได้ 64,000 + 5,000 = 69,000 บาท = +6.9%
  • ถ้าใส่ทั้ง 200,000 ใน Core ที่ +8% จะได้ 16,000 บาท Satellite จึงตามหลัง 16,000 − 5,000 = 11,000 บาท

หุ้นสองตัวใน Satellite ให้ผลบวก แต่รวมแล้วแพ้ Core เพราะตัวที่ขาดทุนหนักลบมากกว่า ตัวอย่างนี้คือเหตุผลที่ต้องเทียบ Satellite กับ Core ในช่วงเวลาเดียวกัน และประเมินจากผลรวมของทุกตัว ไม่ใช่ดูแค่ตัวที่ชนะ (ผลตอบแทนทุกตัวเป็นสมมติ)

6. ตัวอย่างกับดัก: Satellite โตจนเป็นแกนเอง

ถ้า Satellite ขึ้นแรงปีแล้วปีเล่าโดยไม่ปรับ น้ำหนักอาจจาก 20% เป็น 35% ของพอร์ตโดยไม่ได้ตั้งใจ ความเสี่ยงเฉพาะหุ้นรายตัวจึงสูงกว่าที่วางไว้มาก การตั้งเพดานรวมของ Satellite และตรวจน้ำหนักเป็นระยะ (บท 90) คือวิธีกันไม่ให้ตัวเลือกที่ตั้งใจจำกัดกลายเป็นตัวหลัก

7. แบบฝึกหัด

  1. พอร์ต 500,000 บาท Core 70% Satellite 30% ถ้า Satellite ขาดทุน 40% และ Core ไม่เปลี่ยน พอร์ตรวมเสียกี่บาทและกี่เปอร์เซ็นต์
  2. จากข้อ 1 ถ้า Core ลด 25% ด้วย พอร์ตรวมลดกี่เปอร์เซ็นต์
  3. Satellite 80,000 บาท แบ่ง 5 ตัวเท่ากัน ถ้าหนึ่งตัวเหลือศูนย์ พอร์ตรวม 800,000 บาทเสียกี่เปอร์เซ็นต์
  4. Satellite ได้ผลตอบแทนรวม +3% ขณะที่ Core +9% ในปีเดียวกัน ควรสรุปอย่างไร และอะไรที่ควรดูเพิ่มก่อนสรุป
เฉลย
  1. Satellite = 150,000 บาท เสีย 150,000 × 40% = 60,000 บาท = 60,000 ÷ 500,000 = 12%
  2. Core = 350,000 ลด 25% = 87,500 บาท รวมเสีย 87,500 + 60,000 = 147,500 บาท = 29.5%
  3. ตัวละ 80,000 ÷ 5 = 16,000 บาท เสีย 16,000 ÷ 800,000 = 2.0% ของพอร์ต
  4. Satellite ตามหลัง Core ในปีนี้ 6 จุด แต่ปีเดียวไม่พอสรุป ควรดูหลายปี หลังหักต้นทุนและภาษี และดูว่าเกิดจากหุ้นไม่กี่ตัวหรือทั้งชุด ถ้าตามหลังต่อเนื่อง ให้ถามว่าควรย้ายเงินไป Core หรือไม่

สรุปบทนี้

  • Core คือแกนต้นทุนต่ำที่กระจายกว้าง Satellite คือส่วนที่เหลือสำหรับความตั้งใจเฉพาะ
  • Satellite 20% ขาดทุน 50% กระทบพอร์ตรวม −10% จำกัดความเสียหายได้
  • กำหนดเพดาน ตั้งกฎซื้อ-ขาย และเทียบผล Satellite กับ Core อย่างซื่อตรง
  • ประเมิน Satellite ด้วยผลรวมทุกตัวเทียบกับ Core (ตัวอย่าง Satellite +2.5% เทียบ Core +8% ตามหลัง 11,000 บาท) และอย่าปล่อยให้ Satellite โตเกินเพดาน

บทนี้เป็นกรอบการจัดพอร์ตที่ใช้กันทั่วไป ยังไม่ได้ตรวจกับแหล่งทางการ ไม่มีสัดส่วนที่ถูกต้องตายตัว และไม่ได้อ้างผลตอบแทนใดๆ หลักการกระจายความเสี่ยงและสัดส่วนตามความสามารถรับความเสี่ยงสอดคล้องกับคู่มือ SEC ในบท 86 ตัวอย่างเป็นตัวเลขสมมติที่คำนวณซ้ำแล้ว (200,000 × 50% = 100,000 → 10%; 200,000 → 20%; 800,000 × 30% = 240,000; 240,000 + 100,000 = 340,000 → 34%) ตัวอย่างและแบบฝึกหัดเพิ่มเติมเป็นตัวเลขสมมติที่คำนวณซ้ำแล้ว ไม่ใช่ข้อมูลจริง

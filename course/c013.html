DR คือหลักทรัพย์ที่ซื้อขายในตลาดหลักทรัพย์ไทยเป็นเงินบาท แต่อ้างอิงหุ้นต่างประเทศ บทนี้สรุปลักษณะ ตามข้อมูลของ SET และ ก.ล.ต. และสิ่งที่ต้องอ่านก่อนซื้อ

1. DR คืออะไร

ตามที่ SET ระบุ DR เป็นหลักทรัพย์ที่จดทะเบียนให้ซื้อขายได้เหมือนหุ้นในตลาดหลักทรัพย์ฯ ช่วยให้ลงทุนในหลักทรัพย์ต่างประเทศโดยซื้อขายเป็นเงินบาท ผู้ถือมีสิทธิประโยชน์เสมือนลงทุนในหลักทรัพย์ต่างประเทศโดยตรง ก.ล.ต. ระบุว่า DR ออกโดยผู้ออกที่ได้รับอนุญาตจาก ก.ล.ต.

2. ใครออก และอ้างอิงอะไร

  • ผู้ออก DR ต้องได้รับอนุญาตจาก ก.ล.ต. โดยซื้อหลักทรัพย์ต่างประเทศมาแล้วเสนอขายต่อนักลงทุนไทย
  • หลักทรัพย์อ้างอิงคือหุ้นสามัญหรือ ETF ที่ซื้อขายในตลาดต่างประเทศตามที่ ก.ล.ต. กำหนด
  • มีสองประเภท: ตราสารแสดงสิทธิของผู้ฝากทรัพย์สิน (1 DR = หลักทรัพย์ต่างประเทศ 1 หน่วย) และใบแสดงสิทธิในผลประโยชน์ (ตั้งแต่ 1 DR ขึ้นไป = 1 หน่วย เช่น 10 DR = 1 หุ้น)
  • ชื่อย่อไม่เกิน 10 ตัวอักษร โดย 8 ตัวแรกคือชื่อหลักทรัพย์ต่างประเทศ และ 2 ตัวถัดไปคือหมายเลขผู้ออก (ตัวอย่างจาก SET: APPR99)

3. ซื้อขายอย่างไร

4. ผลตอบแทน สิทธิ และต้นทุน

  • กำไรส่วนต่างราคา: SET ระบุว่าได้รับการยกเว้นภาษี เช่นเดียวกับหลักทรัพย์อื่นที่ซื้อขายในตลาดหลักทรัพย์ไทย (บท 27)
  • เงินปันผลและสิทธิประโยชน์: ผู้ถือมีโอกาสได้รับเป็นเงินบาท หลังหักค่าใช้จ่ายดำเนินการ (ถ้ามี) ตามข้อกำหนดสิทธิ ผู้ออกอาจเรียกเก็บค่าธรรมเนียมเมื่อจ่ายสิทธิประโยชน์
  • สิทธิโหวต: มีโอกาสได้รับตามเงื่อนไขในสัญญารับฝาก DR
  • ค่าธรรมเนียมซื้อขาย: เหมือนหุ้นทั่วไป

5. ความเสี่ยงที่ SET ระบุ

  • ความผันผวนของอัตราแลกเปลี่ยน
  • ความผันผวนของราคาหลักทรัพย์ต่างประเทศ
  • ความผันผวนของราคา DR เอง ซึ่งอาจต่างจากราคาหุ้นต้นทาง (บท 14)

SET แนะนำให้อ่านสัญญารับฝาก DR ของแต่ละตัวก่อนลงทุน เพราะเงื่อนไข วิธีการ และค่าใช้จ่ายระบุไว้ในนั้น ผู้ออกอาจดูแลสภาพคล่องเอง หรือจัดให้มีผู้ทำหน้าที่นี้ (บท 6) นอกจากนี้ SET ระบุว่า DRx ย้ายมาซื้อขายในรูปแบบ DR ตั้งแต่วันที่ 6 พฤษภาคม 2568

6. ดูข้อมูลได้ที่

หน้า รวม DR และ เครื่องมือคำนวณ Premium DR ในเว็บนี้ และหน้าผลิตภัณฑ์ DR ของ SET ซึ่งอัปเดตตามประกาศล่าสุด

สรุปบทนี้

  • DR คือหลักทรัพย์ไทยที่ผู้ออกซึ่ง ก.ล.ต. อนุญาตออก อ้างอิงหุ้นหรือ ETF ต่างประเทศ ซื้อขายเป็นบาทในเวลาตลาดไทย
  • กำไรส่วนต่างราคายกเว้นภาษีตามที่ SET ระบุ เงินปันผลรับเป็นบาทหลังหักค่าใช้จ่ายตามข้อกำหนด
  • เสี่ยงทั้งค่าเงิน ราคาหุ้นต้นทาง และราคา DR ที่อาจต่างจากหุ้นต้นทาง ต้องอ่านสัญญารับฝากก่อนซื้อ

ตรวจข้อมูลกับแหล่งทางการเมื่อ 30 ต.ค. 2026: SET: ข้อมูลลักษณะผลิตภัณฑ์ DR (นิยาม ประเภท ผู้ออก ชื่อย่อ สกุลเงิน เวลา กรอบราคา ขั้นต่ำ ภาษีกำไรส่วนต่าง ปันผล สิทธิ ความเสี่ยง ค่าใช้จ่าย DRx) และ ก.ล.ต.: Thai DR (ผู้ออกต้องได้รับอนุญาตจาก ก.ล.ต.) หน้า ก.ล.ต. ไม่ได้ระบุความเสี่ยงหรือการเทียบราคากับหุ้นต้นทาง ส่วนภาษีของเงินปันผล DR ตรวจในบท 27 เงื่อนไขของแต่ละตัวต้องอ่านจากสัญญารับฝากและหนังสือชี้ชวนของ DR ตัวนั้น

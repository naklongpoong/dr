Core-Satellite คือวิธีจัดพอร์ตที่แบ่งเป็นแกนหลักที่มั่นคงกับส่วนเสริมที่ลองความคิดเฉพาะตัว ทำให้อยากเลือกหุ้นเองได้โดยไม่ต้องเอาทั้งพอร์ตไปเสี่ยง บทนี้อธิบายหลักคิดและตัวอย่างเลขคณิต

1. แนวคิด

  • แกนหลัก (Core): สัดส่วนใหญ่ของพอร์ต ใช้ ETF ดัชนีกว้างที่ต้นทุนต่ำ กระจายไปหลายร้อยบริษัท (บท 82) เป้าหมายคือให้ได้ผลตอบแทนใกล้ตลาดโดยไม่ต้องคัดเอง
  • ส่วนเสริม (Satellite): สัดส่วนเล็กกว่า ใช้ลงทุนในหุ้นรายตัว ETF กลุ่มหรือธีม (บท 83) หรือสินทรัพย์อื่นตามมุมมอง

สัดส่วนที่ใช้ไม่มีค่ามาตรฐาน เป็นการตัดสินใจของแต่ละคนตามความรู้และความสามารถรับความเสี่ยง (บท 86)

2. ตัวอย่างสมมติ: ส่วนเสริมช่วยจำกัดความเสียหาย

พอร์ต 1,000,000 บาท แบ่ง Core 80% (800,000) และ Satellite 20% (200,000)

สถานการณ์SatelliteCoreผลต่อพอร์ตรวม
Satellite ขาดทุน 50%−100,000เท่าเดิม−10%
Satellite เพิ่ม 100%+200,000เท่าเดิม+20%
Core ลด 30% และ Satellite ลด 50%−100,000−240,000−34%

แสดงว่าส่วนเสริมที่ผิดพลาดแค่ไหนก็กระทบพอร์ตจำกัด และส่วนเสริมที่ถูกก็ไม่ได้ยกพอร์ตขึ้นไปมาก ความเสี่ยงของพอร์ตส่วนใหญ่ยังมาจาก Core (ตัวอย่างสมมติ ไม่ใช่การคาดการณ์)

3. ข้อดีและข้อจำกัด

  • ข้อดี: แยกความตั้งใจออกจากความรู้สึก ส่วนที่ตั้งใจเสี่ยงมีขอบเขตชัด วัดผลของส่วนเสริมแยกได้ ว่าเลือกหุ้นเองได้ดีกว่าถือ Core เฉยๆ หรือไม่
  • ข้อจำกัด: Core ที่เป็น ETF ดัชนีถ่วงตามมูลค่าอาจมีความกระจุกตัวกับกลุ่มใหญ่อยู่แล้ว และ Satellite ในกลุ่มเดียวกันจะซ้ำ (ดูตัวอย่าง 41.7% ใน บท 83)
  • ต้องมีวินัยไม่ปล่อยให้ส่วนเสริมที่ขึ้นแรงโตจนกลายเป็นส่วนใหญ่ของพอร์ต (บท 90)

4. ตั้งกฎส่วนเสริมก่อนซื้อ

  • กำหนดเพดานรวมของส่วนเสริม และเพดานต่อหนึ่งตำแหน่ง (บท 89)
  • เขียนเหตุผลที่ซื้อ ตัวเลขที่จะตรวจ และเงื่อนไขขาย (บท 97, บท 98)
  • ประเมินผลเทียบกับ Core ที่ช่วงเวลาเดียวกัน ถ้าส่วนเสริมไม่ชนะ Core ต่อเนื่องหลายปีหลังหักต้นทุนและภาษี ก็ถามตัวเองว่าควรย้ายเงินไป Core หรือไม่
  • ต้นทุนและภาษีของการซื้อขายบ่อยในส่วนเสริมดูใน บท 21, บท 29

สรุปบทนี้

  • Core คือแกนต้นทุนต่ำที่กระจายกว้าง Satellite คือส่วนเสริมสำหรับความตั้งใจเฉพาะ
  • ส่วนเสริม 20% ขาดทุน 50% กระทบพอร์ตรวม −10% จำกัดความเสียหายได้
  • กำหนดเพดาน ตั้งกฎซื้อ-ขาย และเทียบผลส่วนเสริมกับ Core อย่างซื่อตรง

บทนี้เป็นกรอบการจัดพอร์ตที่ใช้กันทั่วไป ยังไม่ได้ตรวจกับแหล่งทางการ ไม่มีสัดส่วนที่ถูกต้องตายตัว และไม่ได้อ้างผลตอบแทนใดๆ หลักการกระจายความเสี่ยงและสัดส่วนตามความสามารถรับความเสี่ยงสอดคล้องกับคู่มือ SEC ในบท 86 ตัวอย่างเป็นตัวเลขสมมติที่คำนวณซ้ำแล้ว (200,000 × 50% = 100,000 → 10%; 200,000 → 20%; 800,000 × 30% = 240,000; 240,000 + 100,000 = 340,000 → 34%)
